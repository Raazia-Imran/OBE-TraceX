# Real records workspace
Double-click Start Portal.cmd in the existing project folder. No new clone is needed.
The launcher selects private-data/real.sqlite3 when present, starts local n8n if needed, starts the portal and live reader, then opens the browser.
The database contains authentic historical faculty results and live Google records with the original Coordinator/HOD accounts. Synthetic sessions and generated rehearsal marks are excluded. Earlier databases remain separate backups.
Historical results are source-reference records, not a claim that live Google Forms have passed replay. Missing results and unapproved stages stay visibly pending.
The seven original n8n stage workflows remain the intended production grading/email workflows. The read-only utility only retrieves calculated workbook values. The isolated archive acceptance workflow is a non-production test and is not a grading replacement.
All seven original stage workflows were inactive at the latest check; a full Form-to-original-workflow replay remains pending. Form title/destination mapping, respondent permissions, grading discrepancies and the report-archive branches must be verified before claiming production completion.
